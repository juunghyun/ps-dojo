# ps-dojo 🥋

둘이서 알고리즘 문제를 풀고, PR 리뷰로 서로의 풀이에서 배우는 수련장.

## 운영 방식 — 완전 자동 미러링

```
[프로그래머스/백준 정답] ─백준허브(자동 푸시)→ [개인 아카이브 레포]
                                                    │
                              미러봇(매시 정각) ──────┘
                                    ▼
                  컨벤션 구조로 변환 → PR 자동 오픈 → 회고·리뷰만 사람이
```

1. **문제 선정** — [문제 제안 이슈](../../issues/new?template=problem-suggestion.yml)로 같이 풀 문제를 등록한다. (채팅으로 정해도 무방)
2. **문제를 푼다** — 프로그래머스/백준에서 정답이 나면 백준허브가 **본인 개인 아카이브 레포**에 자동 푸시한다. 이 레포에 직접 커밋할 일은 없다.
3. **미러봇이 PR을 연다** — 매시 정각 Actions가 두 아카이브를 스캔해 새 풀이를 `<플랫폼>/<레벨>-<번호>-<압축제목>/<아이디>.<확장자>` 구조로 변환하고 문제별 PR을 자동 오픈한다. (새 풀이가 6문제 이상 쌓였으면 일괄 PR 하나로. 급하면 Actions 탭에서 "아카이브 미러봇" 수동 실행)
4. **회고 & 리뷰** — 풀이 당사자는 자기 PR에 접근법·막힌 지점을 코멘트로 남기고, 상대방은 코드 리뷰를 남긴다. **이게 이 레포의 존재 이유.**
5. **머지는 자율** — approve를 기다릴 필요 없다. 단, 받은 리뷰 코멘트에는 답을 남긴다. 머지되면 아래 진행표가 자동 갱신된다.

손으로 브랜치 따서 PR 올리는 수동 플로우도 여전히 유효하다 — 컨벤션만 지키면 미러봇과 공존한다. (LeetCode 등 백준허브 미지원 플랫폼은 수동으로)

## 합류하기 — 셀프 등록 (1인당 1회, 사전 초대 불필요)

1. [백준허브 크롬 확장](https://github.com/BaekjoonHub/BaekjoonHub) 설치 → GitHub 인증
2. **본인 개인 아카이브 레포**를 연동한다 (예: `<아이디>/algo-archive`, **public** 필수 — 미러봇이 익명으로 clone). ⚠️ ps-dojo에 직접 연동하지 않는다 — 파일 구조가 달라 서로 덮어쓴다.
3. GitHub 웹에서 [`scripts/mirror_config.json`](scripts/mirror_config.json)을 열고 ✏️(연필)로 본인 항목을 추가한다 — 권한이 없어도 **fork + PR이 자동으로 만들어진다.**
   ```json
   { "username": "<GitHub 아이디>", "archive": "<아이디>/<아카이브 레포>" }
   ```
4. 등록 PR이 머지되면 다음 주기부터 미러링이 시작된다. 리뷰·코멘트는 권한 없이도 가능하고, 본인 PR을 직접 머지하고 싶어지면 그때 collaborator 초대를 받는다.

**기존에 쓰던 백준허브 아카이브를 연동해도 된다** — 첫 스캔 때 연동 시점까지의 과거 풀이는 baseline(`scripts/mirror_baseline.json`)으로 기록만 되고 PR로 올라오지 않는다. 스터디 기록은 지금부터. 단, 과거 문제를 **다시 풀어 코드가 바뀌면** 그때는 PR이 열린다.

## 컨벤션

| 항목 | 규칙 | 예시 |
| --- | --- | --- |
| 문제 폴더 | `<플랫폼>/<레벨>-<문제ID>-<압축제목>/` (브래킷 접두사·특수문자 제거, 한글은 공백 붙임) | `programmers/lv2-42883-큰수만들기/`, `boj/gold3-1005-ACM-Craft/` |
| 풀이 파일 | `<GitHub 아이디>.<확장자>` | `juunghyun.java`, `juunghyun.py` |
| 브랜치 | 미러봇 `mirror/<아이디>/<플랫폼>-<문제ID>` / 수동 `<아이디>/<플랫폼>-<문제ID>` | `mirror/juunghyun/programmers-42883` |
| PR 제목 | `[<플랫폼> <레벨>] <문제ID> <문제이름> - <아이디>` | `[programmers Lv.2] 42883 큰 수 만들기 - juunghyun` |

- 플랫폼 폴더는 `programmers/`, `boj/`, `leetcode/` 등 소문자로 자유롭게 추가한다.
- 같은 문제를 다른 언어로 다시 풀면 확장자만 다른 파일을 같은 폴더에 추가한다.
- 문제 폴더의 `README.md`에는 미러봇이 **문제 설명 전문**(링크·난이도·입출력 예 포함)을 자동으로 넣는다 — 리뷰어가 PR만 보고 문제를 파악할 수 있다.
