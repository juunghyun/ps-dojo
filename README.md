# ps-dojo 🥋

둘이서 알고리즘 문제를 풀고, PR 리뷰로 서로의 풀이에서 배우는 수련장.

## 운영 방식

1. **문제 선정** — [문제 제안 이슈](../../issues/new?template=problem-suggestion.yml)로 같이 풀 문제를 등록한다.
2. **브랜치 생성** — `<본인 아이디>/<플랫폼>-<문제ID>` 이름으로 `main`에서 브랜치를 딴다.
   ```
   git switch -c juunghyun/programmers-42883 main
   ```
3. **풀이 작성** — 문제 폴더에 본인 아이디로 파일을 추가하고 커밋한다.
4. **PR 오픈** — `main`으로 PR을 열면 템플릿에 접근법·복잡도·막힌 지점을 적는다.
5. **리뷰 & 머지** — 상대방이 리뷰 코멘트를 남긴다. **머지는 자율** — approve를 기다릴 필요는 없지만, 리뷰 코멘트에는 답을 남기는 것을 원칙으로 한다.
6. 머지되면 아래 진행표가 자동으로 갱신된다. (수동 작업 없음)

## 컨벤션

| 항목 | 규칙 | 예시 |
| --- | --- | --- |
| 문제 폴더 | `<플랫폼>/<문제ID>-<문제이름>/` (공백 대신 `-`) | `programmers/42883-큰수만들기/` |
| 풀이 파일 | `<GitHub 아이디>.<확장자>` | `juunghyun.java`, `juunghyun.py` |
| 브랜치 | `<아이디>/<플랫폼>-<문제ID>` | `juunghyun/programmers-42883` |
| PR 제목 | `[<플랫폼>] <문제ID> <문제이름> - <아이디>` | `[programmers] 42883 큰 수 만들기 - juunghyun` |

- 플랫폼 폴더는 `programmers/`, `boj/`, `leetcode/` 등 소문자로 자유롭게 추가한다.
- 같은 문제를 다른 언어로 다시 풀면 확장자만 다른 파일을 같은 폴더에 추가한다.
- 문제 폴더에 `README.md`를 두면 문제 링크·메모를 남길 수 있다. (선택)
